# Evergreen Web Standards Radar (`[REF-01]` – `[REF-08]`)

Kanoniczny rejestr zewnętrznych repozytoriów referencyjnych i standardów inżynieryjnych zintegrowanych z architekturą **TwojaStronaWWW (`VPS` & `_site-template`)**.

| ID | Obszar architektoniczny | Zewnętrzne źródło / Standard | Wdrożenie w repozytorium |
| :--- | :--- | :--- | :--- |
| **`[REF-01]`** | **Server & `.htaccess` Hardening** | [`h5bp/server-configs-apache`](https://github.com/h5bp/server-configs-apache) | Kompresja `mod_brotli` + `mod_deflate`, nagłówki izolacji procesu `Cross-Origin-Opener-Policy: same-origin-allow-popups`, `Cross-Origin-Resource-Policy: same-site`, `HSTS`, `CSP`, `Permissions-Policy`, blokada ukrytych plików (z wyjątkiem `/.well-known/`) oraz nowoczesne typy MIME (`avif`, `webp`, `md`, `webmanifest`). |
| **`[REF-02]`** | **Kolejność `<head>` & Nawigacja `0 ms`** | [`rviscomi/capo.js`](https://github.com/rviscomi/capo.js) & [`web.dev/baseline`](https://web.dev/baseline) | Rygorystyczna kolejność znaczników w `<head>` (`charset` -> `viewport` -> `title` -> `preconnect` -> `stylesheet` -> meta SEO/JSON-LD) minimalizująca *First Contentful Paint*, oraz deklaratywne `<script type="speculationrules">` (`eagerness: "moderate"`, z wykluczeniem `/api/*`). |
| **`[REF-03]`** | **Vanilla CSS Baseline (2026)** | [`argyleink/open-props`](https://github.com/argyleink/open-props) & [`web.dev/baseline`](https://web.dev/baseline) | Natywne tokeny CSS, `color-scheme: dark light` w `:root`, stabilny układ bez skakania paska przewijania (`scrollbar-gutter: stable` na `html`), płynne przejścia między podstronami `@view-transition { navigation: auto; }` (wewnątrz `prefers-reduced-motion: no-preference`) oraz typografia `text-wrap: balance` (nagłówki) i `text-wrap: pretty` (akapity). |
| **`[REF-04]`** | **Dostępność Cyfrowa WCAG 2.2 AA** | [`w3c/aria-practices`](https://github.com/w3c/aria-practices) & [`alphagov/govuk-frontend`](https://github.com/alphagov/govuk-frontend) | Link pomijania nawigacji `.skip-link`, semantyczne role ARIA (`role="alert"`, `role="status"`), widoczny fokus `:focus-visible`, obsługa klawiatury (`Escape`, `Tab`) oraz poszanowanie `prefers-reduced-motion`. |
| **`[REF-05]`** | **Bezpieczeństwo Aplikacji i PII Guard** | [`OWASP/ASVS`](https://github.com/OWASP/ASVS), [`OWASP/CheatSheetSeries`](https://github.com/OWASP/CheatSheetSeries) & `polanon` (MIT) | Walidacja nagłówka `Sec-Fetch-Site` (blokada `cross-site`), tokeny CSRF weryfikowane przez `hash_equals`, limit `CONTENT_LENGTH <= 65536` (`HTTP 413`), blokady plikowe `flock(LOCK_EX)`, `@session_write_close()`, WAF L7 (w tym blokada `iframe[srcdoc]` i gadżetów `mathlive#virtual-keyboard-message` + 15-min IP Penalty Box), Zero-PII Rate Limiting (`SHA-256` z solą) oraz deterministyczne maskowanie polskich danych PII (`services/ai-router/src/pii-guard.php`: sumy kontrolne PESEL, NIP, REGON, dowód osobisty, IBAN, adresy uliczne odporne na ReDoS, pseudonimizacja `HMAC-SHA256` i `StreamRestorer` SSE). |
| **`[REF-06]`** | **Polityka Podatności RFC 9116** | [`securitytxt.org`](https://securitytxt.org/) (RFC 9116) | Standardowy plik `/.well-known/security.txt` z aktywną datą `Expires:`, punktem kontaktowym `Contact:` i adresem kanonicznym `Canonical:`. |
| **`[REF-07]`** | **Optymalizacja dla AI Search (GEO) & WebMCP** | [`llmstxt.org`](https://llmstxt.org/) & [`webmachinelearning/webmcp`](https://github.com/webmachinelearning/webmcp) | Plik `/llms.txt` podpięty w `<head>` (`<link rel="alternate" type="text/markdown" href="/llms.txt">`), jawnie dozwolony w `robots.txt` (`Allow: /llms.txt`) oraz rejestracja narzędzia `ask_site_assistant` dla natywnych agentów przeglądarkowych przez imperatywne API **W3C WebMCP (`document.modelContext`)** w `services/ai-router/src/widget.js`. |
| **`[REF-08]`** | **SEO On-Page & Schema.org** | [`schema.org`](https://schema.org/) & [`indexnow.org`](https://www.indexnow.org/) | Pełny graf wiedzy `@graph` JSON-LD (`Organization`, `WebSite`, `WebPage`, `Service`, `FAQPage`), kanoniczne przekierowanie `301` non-www oraz atrybut `data-nosnippet` na kontenerze widgetu AI. |
